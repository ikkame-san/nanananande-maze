# ななななんで迷路

[ブラウザで遊ぶ](https://ikkame-san.github.io/nanananande-maze/)

`index.html` をブラウザで開くと遊べます。インストール、通信、外部ライブラリは不要です。

- 8マスの行と7マスの行を交互に並べた7行の六角形、合計53マス。
- スタートの「な」を1文字目として、**な→な→な→な→ん→で**を繰り返します。
- 辺で接する隣のマスに進み、同じマスは2度通れません。
- ゴールの「で」に着いたらクリア。全マスを通る必要はありません。
- マスをクリック／タップして移動。直前のマスを押すと1手戻ります。
- キーボードは Tab で迷路に入り、矢印でマスを選び、Enter または Space で移動。
- 戻る、やり直し、PNG画像の保存に対応。操作ボタンは大きめの太字で表示します。
- 日本時間の今日の日付をシードにして、毎日同じ問題を表示します。日付欄では先月1日から今日までの問題を選べます。未来の日付は選べません。「今日の迷路」で当日の問題に戻れます。
- 問題が表示されてからゴールまでの時間を計測し、クリア時間を0.1秒単位で表示します。「はじめから」と日付の変更は確認後に進み具合と計測時間をリセットします。
- タイトルを左上、ルール図を右上にまとめたコンパクトなヘッダー。ルールは6個の六角形と、「で」から最初の「な」へ戻る矢印の図で表示。
- 右上の「ルール」を押すと、ルール図と3項目の説明が開きます。通常は折りたたんで表示します。
- 「画像として保存」で問題のPNG画像を直接ダウンロードできます。
- 投稿用PNGは1200 × 1200ピクセル。タイトル・ルール図・盤面を1枚にまとめ、問題番号・正解数・答えやプレイ途中の経路は含めません。印刷・PNG・ルール図は盤面と同じ文字色を使用します。
- 保存画像はタイトル、横長のルール枠、迷路の順に配置。ルール枠の中は図と箇条書きを横に並べ、余白を抑えています。外周はオレンジ一色、内側はクリーム色で、タイトルの上下に少し余白を設けています。
- ブラウザの印刷ショートカットからも、同じ問題専用レイアウトで印刷できます。

## ランダム生成と正解の一意性

まず36マス（「ななななんで」6周分）の正解経路を作り、その上に文字を配置します。同じ方向への直進は最大2歩（3マス）までに制限し、少なくとも14回曲がる道だけを採用します。また、連続する5歩に3方向以上を含めることで、2方向を交互に繰り返す長い階段状の道も避けます。

正解経路の離れた部分同士が辺で隣り合うことは許可します。経路上の文字だけで別解が生じる候補は採用せず、さらに残りの文字を配置した盤面全体を検査して、正解が1通りになることを確認します。

長い経路でも生成が安定するよう、途中までの経路で別の順路が生じ、同じ文字周期で残りの経路につながる場合は、その候補を早めに除外します。隣り合うこと自体は制限しません。

残りのマスを配置した後、スタートからゴールまでの経路を「文字列の何番目か」と「訪問済みマス」を持つ深さ優先探索で調べます。別解があれば、その経路上の正解に含まれないマスの文字を変更して再検査します。探索が完了して正解がちょうど1本の場合だけ採用します。

紛らわしい文字を追加する場合も、変更のたびに同じ検査を実施します。探索上限に達した盤面は、一意と判定しません。ランダムな経路の生成が難航した場合は、検証済みの経路・盤面を基に残りの文字をランダム化し、最後に再度検査します。

日付を `YYYYMMDD` の数値に変換してシードにします。ページのURLには `?date=YYYY-MM-DD` を保存するので、同じ日付のURLでは同じ盤面になります。範囲外・不正な日付のURLは今日に戻します。HTMLファイルを直接開いた場合も利用できます。

## 検証

Node.js がある環境で `node verify.cjs` を実行すると、実際のHTMLに含まれる生成コードを読み込み、複数シードについて別実装の探索で正解が1本であることと、直進・曲がり回数・階段状経路の制限を確認します。

`node verify-dates.cjs` で、日本時間の日付境界・選択範囲・未来や不正な日付の拒否を検証できます。
